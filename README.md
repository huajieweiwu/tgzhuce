在手机号码输入框中，填写一个由你本人长期使用的手机号码。填写完成后，点击Next、箭头按钮或者页面中的继续按钮。不同版本的Telegram客户端按钮名称可能不一样，但是意思基本都是继续提交手机号码。

Telegram可能会邀请你上传头像，并询问是否允许访问通讯录、照片、文件、麦克风和摄像头等权限。头像可以稍后再设置，不会影响账号注册。通讯录权限也不是注册账号的必要条件。如果你允许同步通讯录，Telegram会读取联系人姓名和号码，并帮助你发现已经注册Telegram的联系人。如果你不想同步通讯录，也可以拒绝这个权限，后面再通过用户名或者邀请链接添加联系人。

## 五、Telegram收不到验证码怎么办？

注册Telegram账号时收不到验证码是一个非常常见的问题！当你也遇到这种情况时，不要一直点击发送验证码，也不要在短时间内频繁更换手机号码。这样操作不仅不一定能解决问题，反而可能触发Telegram的安全限制。如果你一直收不到验证码，可以按照下面的顺序逐项排查。

1. 检查手机号码格式。

首先检查国家或地区代码是否正确，并确认手机号码有没有多写、少写或者输错数字。Telegram要求用户使用完整的国际号码格式。如果国家区号选错了，或者手机号码格式不正确，验证码就可能无法正常发送。

2. 检查已经登录Telegram的设备。

如果这个手机号码以前注册过Telegram，验证码可能不会通过短信发送，而是会发送到其他已经登录的Telegram客户端中。你可以检查旧手机、平板、电脑端，以及同一部手机上的其他Telegram客户端，看看有没有收到Telegram官方对话发来的验证码。

3. 等待页面倒计时结束。

Telegram发送验证码后，页面一般会显示倒计时。你应当先等待倒计时结束，然后再使用页面提供的重新发送选项。不要在倒计时还没有结束时反复操作，也不要连续请求验证码。连续请求验证码可能触发Telegram的安全限制，导致验证码暂时无法继续发送。

4. 检查短信拦截功能。

你可以检查手机里的垃圾短信、骚扰拦截记录和安全软件记录，确认验证码短信有没有被系统自动拦截。如果你的手机号码无法接收国际短信，也可能收不到Telegram验证码。遇到这种情况时，可以向手机运营商确认这个号码是否支持接收国际短信。

5. 更新Telegram客户端。

如果Telegram客户端版本太旧，可能会出现登录页面异常、验证码页面无法刷新，或者客户端连接失败等问题。建议你先卸载来源不明的Telegram客户端，然后通过Telegram官网、Google Play或者App Store重新安装最新版本。

6. 检查网络连接。

如果Telegram客户端一直显示Connecting，说明客户端可能没有正常连接到Telegram服务器。你可以重新连接网络，切换到更稳定的网络环境，然后关闭并重新打开Telegram客户端，再重新尝试注册。

7. 不要频繁更换设备和网络。

短时间内重复提交手机号码、频繁更换设备，或者连续请求验证码，都可能触发Telegram的临时安全限制。如果页面出现Too many attempts、Please try again later或者类似提示，就不要继续反复尝试了。这个时候应当先停止操作，等限制解除后再重新尝试。

8. 联系Telegram官方支持。

如果手机号码格式正确，Telegram客户端也可以正常连接，但是长时间仍然收不到验证码，可以通过Telegram官方支持页面提交问题。提交问题时，建议写清楚完整国际号码、设备系统、Telegram版本、页面错误提示和问题发生时间。不要在公开群组里发布完整手机号码、验证码、恢复邮箱或者其他账号信息。

## 六、Telegram注册成功后怎么做好安全设置？

Telegram注册成功后，不建议马上加入大量群组，也不建议马上联系陌生用户。更稳妥的做法是先把账号安全设置好，尤其是两步验证、手机号可见范围、活跃设备、客户端锁定密码这些设置。这样后面再添加好友、加入群组或者订阅频道时，账号会更安全，隐私也更不容易泄露。

1. 开启两步验证

打开下面的设置路径：Settings→Privacy and Security→Two-Step Verification。进入两步验证页面后，设置一个独立密码，并绑定一个可以长期使用的恢复邮箱。开启两步验证后，新设备登录账号时，除了需要输入验证码之外，还需要输入两步验证密码。即使其他人拿到了你的手机验证码，也不能只靠验证码直接登录你的Telegram账号。需要注意的是，两步验证密码不要和邮箱密码、手机锁屏密码或者其他网站密码相同，恢复邮箱也必须由你本人长期控制。

2. 设置手机号码可见范围

打开下面的设置路径：Settings→Privacy and Security→Phone Number。用户可以根据自己的使用需求，把“谁可以看到我的手机号码”设置为Nobody或者My Contacts。Nobody表示尽量不让其他人看到你的手机号码，My Contacts表示只有你的联系人可以看到你的手机号码。如果你不希望陌生人看到你的手机号，建议把这个选项设置得更严格一些。

3. 检查活跃设备

打开下面的设置路径：Settings→Devices。有些Telegram客户端可能会把这个选项显示为Active Sessions。用户需要检查列表中是否存在陌生手机、陌生电脑、陌生浏览器，或者不认识的登录地点。如果发现可疑设备，应当立即终止对应会话，然后修改两步验证密码。

4. 设置客户端锁定密码

打开Privacy and Security页面后，可以找到Passcode Lock或者类似选项。启用客户端锁定密码后，即使其他人拿到了已经解锁的手机，也不能直接打开Telegram查看聊天记录。如果你的设备支持指纹识别或面容识别，也可以配合生物识别功能一起使用。

5. 谨慎同步通讯录

如果你不希望Telegram持续同步手机通讯录，可以进入隐私与数据相关设置，关闭联系人同步。关闭后，Telegram就不会继续同步你的手机通讯录。已经同步过的联系人数据，也可以在设置里进行删除。对于普通用户来说，通讯录同步不是注册Telegram账号的必要步骤，你也可以通过用户名、群组或者邀请链接添加联系人。

6. 创建公开用户名

打开Settings页面后，找到Username选项，即可创建公开用户名。公开用户名可以包含英文字母、数字和下划线。设置成功后，其他用户可以通过用户名搜索并联系你，不需要知道你的手机号码。不过，公开用户名也会出现在Telegram全局搜索结果中。只要对方找到这个用户名，就可能向你发送消息。因此，如果你不希望被陌生用户搜索到，也可以暂时不设置公开用户名。

设置公开用户名后，每个用户都可以获得对应的t.me个人链接。其他人打开这个链接后，可以直接进入对应的Telegram个人资料页或聊天页面，不需要先保存手机号码。不过，打开别人发来的t.me链接时，一定要先核对链接拼写、头像和显示名称。诈骗者可能会使用相似字母、相似头像和相似名称冒充真实用户。

## 八、Telegram怎么加入群组？

Telegram群组主要用于多人交流。加入群组后，群组成员可以在权限允许的情况下发送消息、回复内容、分享文件，也可以参与群内讨论。对于新用户来说，加入群组前要先确认群组来源是否可靠，不要看到名称像“官方”“客服”或者“认证”，就直接相信这个群组。大家可以通过下面两种方式加入Telegram群组。

### 方法一：通过群组邀请链接加入

用户可以在手机或电脑中打开群组邀请链接。打开链接后，Telegram会显示群组名称、头像和部分群组信息。确认群组没有问题后，再点击Join Group或者Join按钮加入群组。

需要注意的是，群组管理员可以随时撤销邀请链接。链接被撤销后，原来的链接会立即失效。如果你打开链接后无法加入群组，可能是链接已经过期，也可能是群组管理员关闭了这个邀请入口。

### 方法二：通过群用户名搜索

部分公开群组设置了群用户名。用户可以在Telegram搜索框中输入群组用户名，或者输入相关关键词进行搜索。

注意：搜索结果中可能会出现名称相似的群组，所以不要只看群组名称就直接加入。加入之前，建议先通过群组介绍、成员数量、管理员信息和官方发布渠道核对真实性。不要因为群组名称中出现“官方”“客服”“担保”或者“认证”等文字，就直接相信这个群组。

## 九、Telegram怎么订阅频道？

Telegram频道主要用于单向发布信息。你可以把频道理解成一个信息发布窗口，频道管理员负责发布内容，普通订阅者主要负责接收和查看消息。很多资讯类、公告类、资源更新类内容，都会通过Telegram频道来发布。部分频道还会开启评论功能，并把评论区连接到单独的讨论群组。

订阅Telegram频道的方法和加入群组比较相似，主要可以按照下面几个步骤操作：

1. 大家可以通过搜索或者频道邀请链接打开频道页面。
2. 打开频道后，需要先核对频道名称、用户名、介绍和历史内容。
3. 确认频道来源可信后，用户可以点击Join按钮完成订阅。

需要注意的是，Telegram中的频道不一定由Telegram官方运营。频道名称、头像和简介都可以被别人模仿，所以你不能把“能够在Telegram中搜索到”理解为“已经经过官方审核”。

如果你是通过别人发来的链接进入频道，建议先核对链接来源，再查看频道历史内容和发布风格。确认没有问题后，再决定是否订阅这个频道。

## 十、Telegram怎么发送消息？

你打开联系人对话或者群组对话后，可以在底部输入框中发送文字消息。如果你想发送图片、视频、文件、联系人或者位置信息，可以点击回形针、加号或者附件按钮。不同系统的Telegram客户端，按钮位置可能会有一点差异，但是整体操作方式基本一致。

通过Telegram发送文件或者接收文件时，大家需要注意下面几个问题：

1. 不要打开来源不明的可执行文件、压缩包和脚本文件。
2. 不要向陌生机器人上传身份证、银行卡、私钥、助记词、验证码或者其他敏感信息。
3. 不要因为对方使用了和官方相似的头像，就直接相信对方是真正的客服。
4. 不要把Telegram登录验证码、两步验证密码和邮箱验证码发送给任何人。

需要特别注意的是，Telegram官方不会通过陌生私聊向你索要登录验证码。如果有人在私聊中让你发送验证码、点击陌生链接或者登录第三方网站，一定要谨慎处理。

## 十一、Telegram怎么发私密信息？

如果你需要进行一对一的端到端加密聊天，可以打开对方的个人资料，点击更多选项，然后选择Start Secret Chat。Secret Chat就是Telegram里的私密聊天，它和普通聊天不一样，更适合用于隐私要求比较高的一对一聊天。

Telegram的私密聊天主要有下面几个特点：

1. Telegram私密聊天使用端到端加密，只有参与聊天的两台设备可以读取消息内容。
2. Telegram私密聊天不会像普通云端聊天一样同步到其他设备。
3. Telegram私密聊天和创建它的设备绑定。你更换设备后，原来的秘密聊天不会自动出现在新设备上。
4. 如果你退出Telegram账号，该设备中的私密聊天可能会丢失。
5. Telegram私密聊天可以设置消息自动销毁时间。
6. Telegram私密聊天不支持直接转发消息。

注意：即使你使用了私密聊天，也不能完全阻止对方用另一台设备拍摄屏幕。因此，大家不要向不可信的人发送隐私照片、密码、助记词或者其他重要信息。

## 十二、注册Telegram账号时的常见问题

### 1. Telegram可以不用手机号码注册吗？

不可以。Telegram账号目前需要绑定手机号码。邮箱不能代替手机号码完成账号注册，邮箱主要用于两步验证密码恢复。

### 2. Telegram可以直接在电脑上注册吗？

首次注册Telegram账号时，建议大家使用Android手机、iPhone或者iPad完成。Telegram电脑端和网页版更适合用来登录已经创建好的账号。注册成功后，你可以通过手机号码、应用内验证码或者二维码登录电脑端。

### 3. 中国大陆手机号码可以注册Telegram吗？

可以。填写中国大陆手机号码时，需要选择+86区号，并按照国际格式输入号码。验证码能否正常送达，可能会受到号码状态、运营商短信通道、Telegram安全机制和网络连接等因素影响。如果你一直收不到验证码，不要连续请求验证码，也不要在短时间内频繁切换手机号码。

### 4. 可以使用临时接码号码注册Telegram吗？

不建议。临时号码可能被多人使用，也可能在一段时间后被重新分配。你一旦失去对这个号码的控制，就可能无法重新登录或找回Telegram账号。

### 5. Telegram注册后必须设置用户名吗？

不需要。用户名属于选填内容。不设置用户名，不会影响你正常聊天。但是，如果你没有设置用户名，别人可能需要通过手机通讯录、群组或者邀请链接找到你。设置公开用户名后，陌生人可以在Telegram全局搜索中找到你的账号，并向你发送消息。

### 6. 别人能看到我的手机号码吗？

别人能不能看到你的手机号码，主要取决于你的Telegram隐私设置，以及对方是否已经保存了你的号码。你可以进入Settings、Privacy and Security和Phone Number，调整手机号码的可见范围。

### 7. Telegram所有聊天都使用端到端加密吗？

不是。普通私聊、群组和频道都属于云端聊天。只有单独创建的秘密聊天，才会使用端到端加密，而且秘密聊天不会同步到其他设备。

### 8. 为什么我不能给陌生人发送消息？

如果你的账号曾经因为发送垃圾消息被其他人举报，Telegram可能会限制这个账号主动联系非联系人。大家不要批量添加陌生人，不要重复发送广告，也不要在多个群组中刷屏。如果你认为账号限制存在错误，可以通过Telegram提供的申诉入口处理。

### 9. 更换手机号码后需要重新注册吗？

不一定。你可以在Telegram设置中使用Change Number功能，把现有账号迁移到新号码。完成迁移后，云端联系人、消息和媒体仍然可以保留。需要注意的是，更换手机号码前，你必须能够正常登录原账号，并且可以控制新的手机号码。

## 十三、注册Telegram账号总结

Telegram注册本身并不复杂，真正需要注意的是手机号码、验证码和账号安全。大家应该先通过官方渠道下载Telegram客户端，再使用自己长期控制的手机号码完成注册。如果验证码没有通过短信发送，可以先检查其他已经登录的设备，看看Telegram官方对话里有没有收到验证码，而不是连续请求验证码。

在使用Telegram时，大家还需要警惕陌生私聊、虚假客服、仿冒频道、恶意机器人和来源不明的文件。任何人向你索要Telegram验证码、两步验证密码或者邮箱验证码时，都不要提供。

只要按照正确的步骤完成Telegram注册，并养成良好的账号安全习惯，Telegram就可以成为一个方便的跨设备通讯和信息订阅工具。
